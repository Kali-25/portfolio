# Kali Saikiran - Portfolio

🌐 **Live Site:** [saikiran.cloud](https://saikiran.cloud)

A modern, responsive portfolio website showcasing my experience as a DevOps Engineer.

## 🚀 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Styling:** Custom CSS with glassmorphism effects
- **Hosting:** Cloudflare Workers
- **Domain:** GoDaddy + Cloudflare DNS

## ✨ Features

- 🎨 Modern glassmorphism UI design
- 📱 Fully responsive layout
- ⚡ Fast loading with Cloudflare CDN
- 🌙 Dark theme with gradient accents
- 🎭 Smooth animations & transitions
- 📧 Contact form with mailto integration

## 📂 Project Structure

```
portfolio/
├── index.html        # Main HTML file
├── styles.css        # All styles
├── script.js         # JavaScript functionality
├── wrangler.jsonc    # Cloudflare Workers config
└── README.md         # This file
```

## 🛠️ Local Development

```bash
# Start local server
python3 -m http.server 8080

# Open in browser
http://localhost:8080
```

## 🚀 Deployment

Automatically deployed to Cloudflare Workers on push to `main` branch.

```bash
git add .
git commit -m "Your message"
git push origin main
```
